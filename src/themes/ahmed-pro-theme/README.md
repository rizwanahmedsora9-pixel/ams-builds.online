# Ahmed Pro Theme

A professional, fully responsive theme for Edge CMS. Phones, tablets and desktops are covered with fluid layouts; light/dark mode, dropdown menus, social icons and a rich footer are built in.

## Install
1. Keep the single `ahmed-pro-theme/` root folder inside the ZIP.
2. In **Appearance → Themes**, upload the ZIP, validate, preview, activate.
3. Open the theme's Customizer settings and fill in contact details and social links.

## What you get
- **Header:** optional top bar (tagline, phone, email, social icons), sticky main bar, logo or built-in mark, dropdown sub-menus, search icon, dark-mode button, mobile slide-down menu.
- **Home:** hero (headline, sub-headline, two buttons), page tiles, featured posts, latest posts (first post is a wide feature card).
- **Pages:** title banner, readable typography, styled breadcrumbs and child-page blocks rendered by the CMS.
- **Posts:** category chips, date/author, featured image, tag chips, share buttons (Facebook, X, WhatsApp, LinkedIn, copy link), comments styling.
- **Archive / Search / 404:** card grids, pagination, search form, friendly 404.
- **Footer:** about + contact column, footer menu, pages list, social icons, back-to-top button.
- **Extras:** inline SVG icons (no external requests), RTL-friendly CSS, reduced-motion support, print styles, skip link.

## Customizer settings
Accent colour, content width, search / dark-mode / top-bar toggles, homepage headline, sub-headline and two buttons, contact email / phone / address, footer note, and links for Facebook, Instagram, X, YouTube, LinkedIn, GitHub and WhatsApp (digits only, with country code, e.g. `923001234567`).

## Menus
Assign menus to `primary` and `footer` in the CMS Menus screen. Sub-menus appear when a primary menu item exposes `children`.
